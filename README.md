# 한/영 전용 입력 언어 배지 오버레이

## 해당 프로젝트의 시작
슬프게도 해당 프로젝트는 윈도우를 사용할 수 밖에 없는 상황에서 윈도우를 원격 접속하여 한/영 변환을 자유롭게 하기 위해 시작되었습니다.
프로그램을 찾던 중, jwShiftSpaceKey를 찾게 되었고 마우스 커서를 따라오는 한/영 전환 상태의 배지가 너무 마음에 들었습니다.

```
패스워드에 한글을 자주 치는 개발자라면 공감할 것입니다.
```

하지만, 정상적으로 동작하지 않는 케이스가 있었고 이를 최신버전으로 찾기 위해 자료를 검색해보았으나, 블로그는 닫으신 상태였고 더 이상 업데이트가 없는 것을 확인하게 되었습니다.

```
처음 jwShiftSpaceKey 만드신 바다야크(badayak)님께 감사드립니다.
```

그래서 쉬프트 스페이스를 전환하고 배지를 생성해 따로오게 만드는 프로그램을 구현해야겠다고 생각하였다. 그래서 클로드와 함께 바이브 코딩을 시작하였습니다.

이 프로젝트는 그 결과물입니다.


## 왜? 한/영 변환은 없어지고 배지만 남았는가?
이미 쉬프트 + 스페이스로 한/영 변환을 쉽게 하기 위해서 사용할 수 있는 PowerToys라는 신뢰할 수 있는 프로그램이 있다는 것을 알게되었습니다.

```
그런데, 굳이? 내가? 신뢰할 수 없는 소프트웨어를 배포하는게 맞는가?
```

그래서 배지 기능만을 가진 프로그램을 만들게 되었습니다.

## 한계점
본 프로젝트는 기본적으로 클로드 코드와 함께하는 바이브 코딩으로 작성되었습니다.

```
분명 나도 개발자이긴하나, 굳이 여기에 엄청난 힘을?
```

그런 마인드로 개발된 프로그램이므로 전.혀. 신뢰도는 없습니다. 거기다가 테스트베드도 없이 제 컴퓨터에 1회 설치가 끝입니다. 물론 현재까지 오류는 없었습니다.

그래서 설치 시, 보안 경고는 무시하고 설치하셔야 할 것 같습니다.
